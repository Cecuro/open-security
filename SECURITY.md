# Security policy

## Supported versions

OpenSec is pre-1.0. Security fixes target the latest npm release and `main`.

## Report a vulnerability

Do not open a public issue. Use GitHub's private vulnerability reporting for this repository. Include the affected version, impact, steps to reproduce, and any suggested fix.

We will confirm receipt, assess the report, and coordinate a fix and disclosure. Do not include source code, credentials, or scan data from systems you do not own or have permission to test.
